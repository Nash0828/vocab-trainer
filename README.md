# 词句助手（Vocab Trainer）

一个基于 **Vue 3 + Node.js + SQLite** 的个人词句背诵工具，支持**单词 / 短语 / 句子**三类内容的录入与背诵，内置多用户体系、随机 / 分组两种背诵模式、错题本、历史统计、查词详情、导入导出等功能。整体采用微信风格 UI，**移动端优先**，同时适配桌面浏览器。

线上示例：https://ibeisong.cn

## 功能特性

### 多用户体系
- **注册 / 登录**：用户名 + 密码（密码 bcrypt 加密存储，非明文）
- **访客模式**：未注册也能直接使用，系统按设备标识自动识别归属数据；清缓存会丢失未注册数据（界面有提示）
- **数据隔离**：不同用户之间的词句库、错题本、历史、设置完全隔离
- **管理员**：内置管理员 `Nash0828`（初始密码 `12345678`，建议登录后立即修改）
  - 查看全部用户（含访客用户，带访客标记）及 IP、创建时间、最近访问、登录日志，支持按关键词 / 类型筛选
  - 重置用户密码、禁用 / 启用、删除用户（操作前需确认）
  - 「我的 → 建议反馈」下钻查看用户提交的反馈列表

### 词句库（单词 / 短语 / 句子）
- **录入**：类型（单词 / 短语 / 句子）、中文、英文；类型为「单词」时额外支持词性（多选，可输入自动匹配）与「区分大小写」开关；短语 / 句子使用多行输入框
- **重复校验**：中文或英文与已有条目重复时阻止录入
- **列表管理**：卡片式列表、类型小标签（短语 / 句子）、搜索 + 类型 + 背熟状态筛选、分页（20 / 50 / 100 条每页）
- **操作**：发音、背诵、查看详情、编辑、重置背诵次数、删除（均为图标按钮）

### 背诵
- **两种背诵模式**（顶部切换）：
  - **随机背诵**：从整个词库出题（加权随机，背诵次数少的优先出现）
  - **分组背诵**：把词句分成若干组，一组一组背；一组背完自动切到下一组
- **分组设置**：组属性 = 序号（背诵出现顺序）/ 名称 / 数量；至少保留 1 组，所有组数量之和须等于词库总数才能保存；新词自动加入数量最少的组；新增组从其他组随机取词、删除组数量随机分摊；支持「重新分配」一键打散重分（保持各组数量不变，进度动态更新）；分组配置保存到服务端
- **组内进度**：每组显示「已背熟 X / 组内 Y」，组下拉使用微信风格底部选择面板
- **出题筛选**：「全部未背熟 / 仅错题本」与类型筛选合并到筛选底部面板，选中的条件以可删除标签（chips）显示；分组模式下为组内口径
- **作答**：显示中文，输入对应英文；单词按「区分大小写」判定，短语 / 句子使用多行输入框；答题卡片顶部以绿色小标签标识短语 / 句子
- **答对**：自动朗读正确发音，**播报完成后再切换下一题**；也可在设置中关闭「答对自动下一题」（默认开启），关闭后答对停留当前题，作答控件置灰，手动进入下一题
- **答错**：显示正确答案，可「重做这一题」（重做答对不计为正式答对，不移出错题本）或手动进入下一题；按回车键也可进入下一题
- **显示答案**：未作答时可查看答案（按答错计入错题本）
- **今日统计**：今日已背（去重）、正确 / 错误（去重）、待练（参与答题的词句数）等卡片，不受筛选影响；点击「待练」跳转词句库
- **快捷键**（桌面）：
  - `Ctrl+P` 朗读当前词句（焦点不离开输入框）
  - `Ctrl+↓` 下一题
  - `Ctrl+A` 显示答案
  - `Ctrl+Q` 查询当前词句详情
  - `Ctrl+R` 答错后重做这一题
  - `Esc` 关闭弹框 / 气泡
- **发音**：单词走有道词典接口，短语 / 句子走百度 TTS（本服务代理），失败回退浏览器系统语音；播放时喇叭图标切换为跳动的声波条

### 错题本
- 答错的词句自动记入错题本（含你当时的错误答案）
- 正式答对后自动移出错题本（「重做这一题」答对不视为正式作答，不移除）
- 支持单个移除、一键清空（两步确认）、分页；可一键跳转背诵指定词句

### 历史记录
- 按天维度汇总每天的正确 / 错误 / 已背去重数量与**每日正确率**
- 点击卡片展开当天作答明细（含错误答案）；展开后卡片头部**吸顶**，方便随时折叠
- 支持清空某天记录、清空全部历史（两步确认）

### 查词详情
- 词句详情弹框：音标、释义、词形变化、例句（有道词典接口，失败回退百度翻译）
- 例句朗读（每句带发音按钮）；例句与词形变化中的单词可点击，弹出气泡查询该单词（含朗读，发音图标紧跟单词）
- 英式 / 美式发音按钮

### 设置
- **答对自动下一题**：开关（默认开启），关闭后答对不再自动跳下一题
- **背熟规则**：设置「答对多少次视为已背熟」（默认 10 次，1–999），已背熟词句不再出题
- **重置全部背诵次数**：一键将所有词句恢复为未背过（两步确认）
- **数据导入 / 导出**：导出 JSON（含词句库、背诵次数、历史、错题本、设置），导入时再选择合并 / 覆盖方式
- **建议反馈**：用户可提交建议反馈，管理员可在「我的」中查看全部反馈列表

## 技术栈

| 层级 | 技术 |
|---|---|
| 前端 | Vue 3 + Vue Router + Vite |
| 后端 | Node.js + Express |
| 数据库 | SQLite（better-sqlite3，单文件数据库） |
| 密码存储 | bcrypt 加密 |
| 发音 | 有道词典接口 + 百度 TTS（服务端代理）+ 浏览器语音 |
| 查词 | 有道词典接口，失败回退百度翻译 |

## 本地开发

### 环境要求
- Node.js 18+（推荐 22+）
- npm

### 安装依赖
```bash
npm install
```

### 启动开发环境（两个终端）

**终端 1：启动后端 API（端口 3000）**
```bash
node server/index.js
```

**终端 2：启动前端开发服务（端口 5173）**
```bash
npm run dev
```

打开浏览器访问 **http://localhost:5173/**

> 前端开发服务已配置代理，`/api/*` 请求会自动转发到后端 3000 端口。

## 生产部署

### 构建并启动
```bash
# 1. 构建前端（输出到 dist/）
npm run build

# 2. 启动服务（同时托管前端页面和 API，端口 3000）
npm start
```

访问 **http://服务器IP:3000/**

### 推荐部署方式（阿里云轻量服务器 / ECS，Ubuntu 22.04）

1. 服务器安装 Node.js 18+ 与 npm
2. 上传项目代码（git clone 或 scp）
3. 安装依赖并构建：
   ```bash
   npm install
   npm run build
   ```
4. 用 pm2 守护进程启动：
   ```bash
   npm install -g pm2
   pm2 start server/index.js --name vocab-trainer
   pm2 save
   ```
5. （可选）配置 Nginx 反向代理到 3000 端口，绑定域名并启用 HTTPS（本仓库已按 `ibeisong.cn` 配置证书样例）
6. 在云服务器控制台放行所需端口（80 / 443 / 3000）

> 提示：`index.html` 已禁用浏览器缓存，部署新版本后用户刷新即可获取最新页面；带 hash 的静态资源可长期缓存。

## 数据存储

所有数据存储在项目根目录下的 `vocab.db` 文件中（SQLite），主要表：

| 表 | 说明 |
|---|---|
| `users` | 用户（含访客与管理员，密码 bcrypt 加密） |
| `user_logs` | 登录 / 退出等操作日志 |
| `sessions` | 登录会话 |
| `words` | 词句（类型、中文、英文、词性、区分大小写、背诵次数、录入时间、所属用户） |
| `groups` | 分组配置（序号、名称、所属用户） |
| `word_groups` | 词句与分组归属关系 |
| `settings` | 用户设置（`masteryThreshold` 背熟阈值、`autoNext` 答对自动下一题） |
| `records` | 背诵记录（按天统计、含作答明细） |
| `wrongbook` | 错题本（含错误答案） |
| `guest_meta` | 访客设备标识映射 |
| `feedbacks` | 建议反馈 |

**备份**：直接复制 `vocab.db` 文件即可；也可使用设置页的「数据导入 / 导出」功能导出 JSON 备份。
