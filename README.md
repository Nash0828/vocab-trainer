# 词句助手（Vocab Trainer）

一个基于 **Vue 3 + Node.js + SQLite** 的个人词句背诵小工具，支持**单词 / 短语 / 句子**三类内容的录入与背诵，内置多用户体系、错题本、历史统计、查词详情、导入导出等功能。整体采用微信风格 UI，**移动端优先**，也适配桌面浏览器。

## 功能特性

### 多用户体系
- **注册 / 登录**：用户名 + 密码（密码加密存储，非明文）
- **访客模式**：未注册也能直接使用，系统按设备标识自动识别归属数据；清缓存会丢失未注册数据（界面有提示）
- **数据隔离**：不同用户之间的词句库、错题本、历史、设置完全隔离
- **管理员**：内置管理员 `Nash0828`（初始密码 `12345678`，建议登录后立即修改）
  - 查看全部用户（含访客用户，带访客标记）及 IP、创建时间、最近访问、登录日志
  - 重置用户密码、禁用 / 启用、删除用户
  - 查看用户提交的建议反馈列表

### 词句库（单词 / 短语 / 句子）
- **录入**：类型（单词 / 短语 / 句子）、中文、英文；类型为「单词」时额外支持词性（多选，可输入自动匹配）与「区分大小写」开关；短语 / 句子用多行输入
- **重复校验**：中文或英文与已有条目重复时阻止录入
- **列表管理**：卡片式列表、类型小标签、搜索（关键字）+ 类型 + 背熟状态筛选、分页（20 / 50 / 100 条每页）
- **操作**：发音、背诵、编辑、查看详情、重置背诵次数、删除（均为图标按钮）
- 桌面端表格支持表头拖拽调整列宽，并持久化

### 背诵
- **出题来源**：全部未背熟词句 / 仅错题本 / 指定某个词句背诵
- **熟练度优先**：加权随机出题，背诵次数少的优先出现
- **作答**：显示中文，输入对应英文；单词按「区分大小写」设置判定，短语 / 句子使用多行输入框
- **答对**：自动朗读正确发音，**播报完成后再自动切换下一题**并聚焦输入框
- **答错**：显示正确答案，可「重做这一题」或手动进入下一题；按回车键也可进入下一题
- **显示答案**：未作答时可查看答案（按答错计入错题本）
- **今日统计**：今日已背（去重）、正确 / 错误（去重）等卡片，不受筛选影响；点击「待练」跳转词句库
- **快捷键**（桌面）：`Ctrl+P` 朗读、`Ctrl+↓` 下一题、`Ctrl+A` 显示答案、`Ctrl+Q` 查词详情、`Esc` 关闭弹框
- **发音**：有道词典接口 → 百度 TTS（本服务代理）→ 浏览器系统语音，三级回退；播放时按钮切换为跳动的声波条图标

### 错题本
- 答错的词句自动记入错题本（含你当时的错误答案）
- 正式答对后自动移出错题本（「重做这一题」答对不视为正式作答，不移除）
- 支持单个移除、一键清空、分页；可一键跳转背诵指定词句

### 历史记录
- 按天维度汇总每天的正确 / 错误 / 已背去重数量
- 点击卡片展开当天作答明细（含错误答案）；展开卡片头部**吸顶**，方便随时折叠
- 支持清空某天记录、清空全部历史（两步确认）

### 查词详情
- 词句详情弹框：音标、释义、词形变化、例句（有道词典接口，失败回退百度翻译）
- 例句朗读（每句带发音按钮）；例句与词形变化中的单词可点击，弹出气泡查询该单词（含朗读）
- 英式 / 美式发音按钮

### 设置
- **背熟规则**：设置「答对多少次视为已背熟」（默认 10 次，1–999），已背熟词句不再出题
- **重置全部背诵次数**：一键将所有词句恢复为未背过（两步确认）
- **数据导入 / 导出**：导出 JSON（含词句库、背诵次数、历史、错题本、设置），支持合并 / 覆盖导入，导入时再选择方式
- **建议反馈**：用户可提交建议反馈，管理员可在「我的」中查看全部反馈列表

## 技术栈

| 层级 | 技术 |
|---|---|
| 前端 | Vue 3 + Vue Router + Vite |
| 后端 | Node.js + Express |
| 数据库 | SQLite（better-sqlite3，单文件数据库） |
| 密码存储 | bcrypt 加密 |
| 发音 | 有道词典接口 + 百度 TTS（服务端代理）+ 浏览器语音 |
| 查词 | 有道词典接口，失败回退百度翻译 |

## 本地开发

### 环境要求
- Node.js 18+（推荐 22+）
- npm

### 安装依赖
```bash
npm install
```

### 启动开发环境（两个终端）

**终端 1：启动后端 API（端口 3000）**
```bash
node server/index.js
```

**终端 2：启动前端开发服务（端口 5173）**
```bash
npm run dev
```

打开浏览器访问 **http://localhost:5173/**

> 前端开发服务已配置代理，`/api/*` 请求会自动转发到后端 3000 端口。

## 生产部署

### 构建并启动
```bash
# 1. 构建前端（输出到 dist/）
npm run build

# 2. 启动服务（同时托管前端页面和 API，端口 3000）
npm start
```

访问 **http://服务器IP:3000/**

### 推荐部署方式（阿里云轻量服务器 / ECS，Ubuntu 22.04）

1. 服务器安装 Node.js 18+ 与 npm
2. 上传项目代码（git clone 或 scp）
3. 安装依赖并构建：
   ```bash
   npm install
   npm run build
   ```
4. 用 pm2 守护进程启动：
   ```bash
   npm install -g pm2
   pm2 start server/index.js --name vocab-trainer
   pm2 save
   ```
5. （可选）配置 Nginx 反向代理到 3000 端口，绑定域名并启用 HTTPS（本仓库已按 `ibeisong.cn` 配置证书样例）
6. 在云服务器控制台放行所需端口（80 / 443 / 3000）

## 数据存储

所有数据存储在项目根目录下的 `vocab.db` 文件中（SQLite），主要表：

| 表 | 说明 |
|---|---|
| `users` | 用户（含访客与管理员，密码 bcrypt 加密） |
| `user_logs` | 登录 / 退出等操作日志 |
| `sessions` | 登录会话 |
| `words` | 词句（类型、中文、英文、词性、区分大小写、背诵次数、录入时间、所属用户） |
| `settings` | 用户设置（背熟阈值等） |
| `records` | 背诵记录（按天统计、含作答明细） |
| `wrongbook` | 错题本（含错误答案） |
| `guest_meta` | 访客设备标识映射 |
| `feedbacks` | 建议反馈 |

**备份**：直接复制 `vocab.db` 文件即可；也可使用设置页的「数据导入 / 导出」功能导出 JSON 备份。
